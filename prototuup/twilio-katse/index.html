Kontrolli numbri operaatorit

Vaata, millise sideettevõtja tagastab numbripäring. Kinnita tulemus ise ja lisa eraldi teenusebränd.

See on ühenduse katse. Eesti teisaldatud numbri praeguse operaatori täpsus vajab veel katsetamist. Ühenduse töötamine üksi ei tõenda vastuse õigsust.

Laadin kohaliku serveri olekut.

Katse kestab aktiveerimisest 72 tundi. Kuni 100 päringut × 0,008 USD = kuni 0,80 USD API kulu. Võimalikud maksud lisanduvad eraldi. Sellel lehel SMS-e ega kõnesid ei saadeta.

1. Operaatori päring

Sisesta oma number

Sobib +372, 00372 või riigikoodita sisend. Piloot toetab 5-ga algavaid 7- või 8-kohalisi Eesti mobiilinumbreid. Tühikud, sulud ja sidekriipsud on lubatud.

Telefoninumber saadetakse sinu nupuvajutusel kohaliku serveri kaudu Twiliole operaatori kontrolliks.

Päringu tegemiseks peab katse olema aktiivne.

Võrgu nimi ei kinnita teenusebrändi, paketti ega numbri omanikku. Kui tulemus ei klapi, paranda sideettevõtja kõrval käsitsi.

2. Sinu kinnitus

Kinnita või paranda valik

Saad valida käsitsi ka siis, kui API ei tööta või internet puudub. Teenusebrändi automaatselt ei täideta.

Päringu järel vajuta „Kasuta seda sideettevõtjat” või kirjuta õige nimi ise.

Valik kinnitatud

Valik püsib ainult avatud lehe mälus. Lehe sulgemine või numbri muutmine eemaldab tulemuse ja kinnituse.

Leht ei kasuta brauseri püsimälu ega analüütikat. Twilio võtmed asuvad ainult kohalikus serveris. 72 tunni ja 100 päringu piir kehtib selle katsetööriista kaudu tehtud päringutele.

Võrdlemiseks saad avada TTJA avaliku numbripäringu uues aknas. Numbripäring ei asenda lepingu sõlmimise isiku- ega esindusõiguse kontrolli.
